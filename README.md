# 學測快問快答

以學測（108 課綱）全範圍為題庫的手機快問快答遊戲。設計目標是**在外面、沒有紙筆時也能刷題**。

線上版：<https://ragorothers-alt.github.io/gsat-fast-review/>（手機打開後「加入主畫面」即可離線使用）


- **免紙筆**：絕大多數題目 20 秒內能心算或判斷；少數需要動筆的數理計算題，用內建的草稿區演算。
- **草稿區**：平板上常駐在題目旁邊（橫放在右、直放在下），手機按 ✏️ 拉出來；支援觸控筆筆壓、紅黑雙色、橡皮擦與復原，用過觸控筆後手掌靠著螢幕也不會亂畫。換題自動翻新頁，按 ↶ 可以翻回上一頁。
- **單手操作**：答案按鈕在拇指區；是非題可以直接把卡片往右滑（對）／往左滑（錯）。
- **不會也不卡關**：按「不會？看解答」不扣分、不算答錯次數，但在複習排程上等同答錯：回到最短間隔、1 分鐘後再出，進錯題本；之後要隔開時間再答對三次才會離開錯題本。
- **短回合**：60 秒快閃、10 題一輪，搭車一兩站就能完成。
- **自由練習**：不計時、不限題數，答對也會停下來看解析，想停再按 ✕ 結算；題目出完自動補下一批，剛答過的不會馬上重出。
- **挑單元練**：95 個單元、每單元至少 100 題，可以只勾想練的單元（例如考前只刷三角函數）。
- **間隔重複**：答錯的很快再出、答對的隔 1／3／7／16 天再複習。
- **錯題延伸**：答錯或按「不會」後，可以按「🔁 練 3 題類似題」，馬上接著練同單元裡最相近的題目；結算畫面也能用這輪的錯題找一整輪類似題來練。
- **一鍵複製去問 AI**：題目卡右上角的 📋 把題目整理成可以直接貼給 ChatGPT 的文字（保留 LaTeX 公式）；作答前複製是請它教怎麼解，作答後複製會附上你的答案、正解與解析，請它解釋錯在哪。結算畫面的錯題也能複製。
- **學習分析**：點首頁的今日進度卡，看近 14 天走勢、各科熟練度，以及失誤率最高的弱點單元；「弱點加強」模式專出最弱的 3 個單元，也可以點單一單元加強。
- **學測倒數與每日目標**：首頁顯示距離學測的天數（預設 116 學測 2027/1/22，可在 ⚙️ 設定裡改），每日目標可選 10～120 題。
- **手機⇄平板同步**：⚙️ 設定裡匯出進度存成檔案，到另一台匯入即可合併；同一題保留較新的紀錄，重複匯入也不會重複計算。
- **回報題目**：覺得題目有錯就按題目卡右上角的 🚩，這題先不出，並可在設定裡複製回報清單交給題庫維護者。
- **離線可用**：安裝到主畫面（PWA）後沒網路也能玩，進度存在手機上。有新版時會在背景下載，回到首頁時自動換上。

畫面是米色方格筆記本風，背景用 three.js 畫了十隻手繪貓咪（每科一隻，圍巾是科目色）：
- 首頁牠們坐在書架上會眨眼、甩尾巴、跟著手指看，點一下就叫醒或哄睡，等於切換科目；
- 作答時當科的貓從題目卡後面探頭，答對開心跳、答錯冒冷汗、看解答會歪頭；
- 結算時這輪出場的貓一起趴在成績卡上。

線條都是程式即時產生的筆觸網格，shader 每秒換 8 格抖動，做出手繪動畫特有的 line boil。

## 開發

```bash
npm install
npm run dev        # 開發伺服器（--host，同一個 Wi-Fi 的手機也能連）
npm test           # 核心邏輯單元測試
npm run validate   # 檢查題庫格式與 LaTeX
npm run build      # 輸出到 dist/（含離線用的 sw.js）
npm run preview    # 預覽建置結果
```

`dist/` 是純靜態檔，且使用相對路徑，可以直接放到 GitHub Pages、Netlify、Cloudflare Pages 等任何靜態網站空間。離線功能需要 HTTPS（或 localhost）。

## 題庫

- 位置：`src/data/questions/<科目>.json`。建置時每科輸出成一個獨立的 JSON 檔（檔名含內容雜湊），開啟時才下載；改版時只有內容變了的科目要重新下載。
- 規範：[docs/question-spec.md](docs/question-spec.md)（欄位、免紙筆原則、LaTeX 寫法）。
- 新增或修改題目後執行 `npm run validate`，0 個錯誤才算完成。

- 單元清單：`src/units.js`，每題的 `topic` 必須是其中之一；驗證器會擋下少於 100 題的單元。

## 程式結構

| 檔案 | 內容 |
| --- | --- |
| `src/scene.js` | three.js 場景：各畫面的貓咪站位、點貓、答題反應 |
| `src/world/` | 手繪筆觸與抖動 shader、貓咪模型與動畫、背景塗鴉、粒子 |
| `src/units.js` | 各科單元清單 |
| `src/srs.js` | Leitner 間隔重複、出題順序 |
| `src/session.js` | 一輪遊戲的計分、連擊、計時 |
| `src/stats.js` | 每日題數與連續天數 |
| `src/analysis.js` | 學習分析：弱點單元、各科統計、每日走勢、學測倒數 |
| `src/sync.js` | 進度匯出、匯入與合併 |
| `src/related.js` | 錯題延伸：找同單元裡最相近的題目 |
| `src/prompt.js` | 把題目整理成貼給 ChatGPT 的文字 |
| `src/data/bank.js` | 開啟時下載各科題庫 |
| `src/storage.js` | localStorage 存取 |
| `src/ui/` | 首頁、作答、結算、學習分析、設定、單元選擇、草稿區與音效 |
| `scripts/validate-questions.mjs` | 題庫驗證器 |
| `vite.config.js` | 建置設定與離線快取（sw.js）產生器 |
