# 學測快問快答

以學測（108 課綱）全範圍為題庫的手機快問快答遊戲。設計目標是**在外面、沒有紙筆時也能刷題**。

線上版：<https://ragorothers-alt.github.io/gsat-fast-review/>（手機打開後「加入主畫面」即可離線使用）


- **免紙筆**：絕大多數題目 20 秒內能心算或判斷；少數需要動筆的數理計算題，用內建的草稿區演算。
- **草稿區**：平板上常駐在題目旁邊（橫放在右、直放在下），手機按右上角的鉛筆拉出來；支援觸控筆筆壓、紅黑雙色、橡皮擦與復原，用過觸控筆後手掌靠著螢幕也不會亂畫。換題自動翻新頁，按 ↶ 可以翻回上一頁。
- **單手操作**：答案按鈕在拇指區；是非題可以直接把卡片往右滑（對）／往左滑（錯）。
- **不會也不卡關**：按「不會？看解答」不扣分、不算答錯次數，但在複習排程上等同答錯：回到最短間隔、1 分鐘後再出，進錯題本；之後要隔開時間再答對三次才會離開錯題本。
- **短回合**：60 秒快閃、10 題一輪，搭車一兩站就能完成。
- **自由練習**：不計時、不限題數，答對也會停下來看解析，想停再按 ✕ 結算；題目出完自動補下一批，剛答過的不會馬上重出。
- **挑單元練**：111 個單元、每單元至少 100 題，可以只勾想練的單元（例如考前只刷三角函數）。只考數學 A 的人可以關掉「數B 專屬主題」，只考數學 B 的可以關掉「空間向量與平面直線」。
- **跨單元綜合**：每科都有一個「跨單元綜合」單元，每題結合同一科的 2–3 個單元（卡片上標「跨單元：平面向量＋三角比」），練學測常見的整合題；關掉其中任一個單元，結合它的跨單元題也不會出。
- **間隔重複**：答錯的很快再出、答對的隔 1／3／7／16 天再複習。
- **錯題延伸**：答錯或按「不會」後，可以按「練 3 題類似題」，馬上接著練同單元裡最相近的題目；結算畫面也能用這輪的錯題找一整輪類似題來練。
- **一鍵複製去問 AI**：題目卡右上角的複製鈕（夾板）把題目整理成可以直接貼給 ChatGPT 的文字（保留 LaTeX 公式）；作答前複製是請它教怎麼解，作答後複製會附上你的答案、正解與解析，請它解釋錯在哪。結算畫面的錯題也能複製。
- **學習分析**：點首頁的今日進度卡，看近 14 天走勢、各科熟練度，以及失誤率最高的弱點單元；「弱點加強」模式專出最弱的 3 個單元，也可以點單一單元加強。
- **考前規劃**：學習分析裡算出照目前步調、考前能把選的範圍練過多少，以及想全部練過一輪每天要做幾題，可以一鍵把每日目標調到夠用的題數。
- **錯題本**：首頁右上角的書本，分成四頁：「錯題」翻完還沒學會的題目（含正解與解析）並直接練一輪；「收藏」是作答時按星星收起來的題目；「重點」是每個單元的考前重點卡；「搜尋」可以找全部題目的題幹、選項與解析（空格隔開找同時出現的詞，$\mathrm{H_2O}$ 打 H2O 就找得到）。收藏和搜尋結果也能直接練一輪。
- **考前重點卡**：111 個單元各有一張，列出必背重點與易錯陷阱，可以左右翻同一科的單元、直接練這個單元；從錯題本、單元面板、學習分析的弱點單元，或題目卡上的單元名稱打開。
- **英文發音**：英文題的卡片上有喇叭，用裝置內建的語音念出句子；作答前空格處停頓，作答後把正解填進去念完整句。
- **學測倒數與每日目標**：首頁顯示距離學測的天數（預設 116 學測 2027/1/22，可在設定裡改），每日目標可選 10～120 題。
- **線上同步**：設定裡按「開啟線上同步」得到一組同步碼，另一台輸入同一組碼就會自動合併作答紀錄、錯題、每日題數、收藏與回報（不用註冊或登入）。開 App、每輪結算後、切換前景／背景時自動同步，沒網路時照常玩、連上再補傳；同一題以較晚作答的為準，兩台當天的題數相加。
- **進度備份**：也可以把進度匯出成檔案，到另一台匯入合併；同一題保留較新的紀錄，重複匯入也不會重複計算。
- **回報題目**：覺得題目有錯就按題目卡右上角的旗子，這題先不出，並可在設定裡複製回報清單交給題庫維護者。
- **每日提醒**：設定裡開啟後，每天到了選的時間、當天目標還沒達成，就會收到通知（Web Push；iPhone 要先加入主畫面）。
- **深色模式與字體大小**：可跟著系統切換成黑板風的深色模式（貓咪外框變成粉筆線）；題目、選項與解析的字可以調大。
- **看得出對錯**：答完後除了紅綠底色，正解會蓋上手繪的圈、選錯的蓋叉，分不出紅綠也看得懂。小螢幕放不下長題目時，先縮小一級字，還放不下就在卡片底部提示往下捲。
- **手機橫放**：橫拿手機時首頁改成左右兩欄、不用捲動；作答時題目卡在左、選項在右，草稿區拉出來會換到右邊。
- **關於與診斷**：設定最下面列出版本、離線快取、進度保護、通知權限與最近的錯誤，一鍵複製給開發者。程式出錯時也會自動回報錯誤訊息、版本與瀏覽器型號（不含作答紀錄與同步碼）。
- **離線可用**：安裝到主畫面（PWA）後沒網路也能玩，進度存在手機上。有新版時會在背景下載，回到首頁時自動換上。iPhone 用 Safari 直接開網頁的話，7 天沒開可能被清掉紀錄，所以練過一輪後會提醒一次怎麼加入主畫面；Android 長按 App 圖示可以直接進「60 秒快閃」「自由練習」「錯題複習」。

畫面是米色方格筆記本風，背景用 three.js 畫了十隻手繪貓咪（每科一隻，圍巾是科目色）：
- 首頁牠們坐在書架上會眨眼、甩尾巴、跟著手指看，點一下就叫醒或哄睡，等於切換科目；
- 作答時當科的貓從題目卡後面探頭，答對開心跳、答錯冒冷汗、看解答會歪頭；
- 結算時這輪出場的貓一起趴在成績卡上。

線條都是程式即時產生的筆觸網格，shader 每秒換 8 格抖動，做出手繪動畫特有的 line boil；畫面每秒重畫 30 張就停，不跟著 120 Hz 螢幕一直畫，比較省電。
介面上的小圖示（火焰、齒輪、旗子、是非題的圈叉…）也是同一套墨線手繪風，放在 `index.html` 開頭的 SVG sprite，不用作業系統的 emoji，各平台看起來都一樣。

## 開發

```bash
npm install
npm run dev        # 開發伺服器（--host，同一個 Wi-Fi 的手機也能連）
npm test           # 核心邏輯單元測試
npm run validate   # 檢查題庫與考前重點卡的格式與 LaTeX
npm run build      # 輸出到 dist/（含離線用的 sw.js）
npm run preview    # 預覽建置結果
npm run e2e        # 端對端測試與無障礙檢查（要先 build；第一次先 npx playwright install chromium）
```

端對端測試（`e2e/`）用 Playwright 在手機與桌機尺寸各跑一次：作答到結算、收藏與搜尋、設定、手機橫放、斷網重新整理，以及用 axe 檢查各畫面在淺色、深色下沒有嚴重的無障礙問題（對比度、標籤、只有公式的選項念不念得出來等）。GitHub Actions 每次推送都會跑，沒過就不部署。

`dist/` 是純靜態檔，且使用相對路徑，可以直接放到 GitHub Pages、Netlify、Cloudflare Pages 等任何靜態網站空間。離線功能需要 HTTPS（或 localhost）。

## 題庫

- 位置：`src/data/questions/<科目>.json`。建置時每科輸出成一個獨立的 JSON 檔（檔名含內容雜湊），開啟時才下載；改版時只有內容變了的科目要重新下載。
- 規範：[docs/question-spec.md](docs/question-spec.md)（欄位、免紙筆原則、LaTeX 寫法）。
- 新增或修改題目後執行 `npm run validate`，0 個錯誤才算完成。
- 考前重點卡：`src/data/keypoints/<科目>.json`，每個單元 5–8 條必背重點、2–4 條易錯陷阱；用 `node scripts/validate-keypoints.mjs` 檢查。

- 單元清單：`src/units.js`，每題的 `topic` 必須是其中之一；驗證器會擋下少於 100 題的單元。
- 範圍：依 108 課綱部定必修與大考中心考試說明逐條比對，題目太少的條目都補到至少 8 題（國文核心古文每篇約 12 題），超出必修的題目改寫成範圍內的題目。另有三種特殊單元：
  - 「跨單元綜合」：每題的 `links` 欄位列出結合的 2–3 個單元；
  - 「數B 專屬主題」（數學）、「探究與實作」（物理、化學、生物、地科）、「史料與歷史解釋」（歷史）：補齊原本單元沒有涵蓋的考試範圍。
- 題型做不到、所以不在題庫裡的：國寫、英文作文與翻譯、長篇閱讀題組、需要看圖表的題目，以及混合題的非選擇部分。

## 線上同步後端

`worker/` 是一個 Cloudflare Worker，資料存在 D1（SQLite），也負責每日提醒的推播。同步碼就是鑰匙：資料庫只存它的 SHA-256；每題一列，各列記下最後修改時的版本號，裝置每次只上傳自己的變動、拉回比自己新的列。合併規則與 `src/sync.js` 相同，測試（`tests/cloud.test.js`）用 Node 內建的 SQLite 跑真正的 Worker 程式，模擬兩台裝置互相同步。

```bash
cd worker
npx wrangler@4 deploy                                   # 部署 Worker
npx wrangler@4 d1 migrations apply gsat-sync --remote   # 套用 migrations/ 裡的資料表變更
npx wrangler@4 secret put VAPID_PRIVATE_JWK             # 推播用的 VAPID 私鑰（JWK 字串，只要設定一次）
```

每日提醒（`worker/src/push.js`）：App 用 Web Push 訂閱，訂閱不綁同步碼，只存推播服務的網址與金鑰、提醒時刻、時區，以及 App 回報的今日進度。Cron 每個整點檢查一次，找出當地時間到了、今天還沒達標也還沒提醒過的訂閱，送出加密過的通知（RFC 8291，測試用 RFC 的範例數值逐位元組比對）。VAPID 公鑰寫在 `wrangler.toml` 與 `src/ui/reminder.js`，兩邊要一致。

錯誤回報（`/v1/log`）：前端未捕捉的錯誤（`src/errors.js`）送到這裡，同一版本、同一則訊息與位置只記一列並累計次數，最多保留 500 列；看最近的錯誤：`npx wrangler@4 d1 execute gsat-sync --remote --command "SELECT * FROM errors ORDER BY last_at DESC LIMIT 20"`。

前端連到的網址在 `src/cloud.js` 的 `SYNC_API`；開發時可以用環境變數 `VITE_SYNC_API` 指到本機的 `wrangler dev`。
免費方案的額度（每天 10 萬次請求、10 萬列寫入）遠超過個人使用量。
