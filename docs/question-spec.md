# 題庫規範

題庫放在 `src/data/questions/<科目>.json`，每個檔案是一個 JSON 陣列。
寫完一定要跑驗證器，0 個錯誤才算完成：

```bash
node scripts/validate-questions.mjs src/data/questions/math.json
```

## 核心原則：不用紙筆也能作答

這個遊戲給學生在通勤、排隊時用手機刷題，**手邊沒有紙筆**。每一題都必須：

1. **20 秒內能心算或判斷**：數學、理化計算最多兩步，數字要小、能整除或好估算；需要列式、畫圖、長除法的題目不要出。
2. **純文字即可作答**：不能依賴圖片、地圖、示意圖。要讀圖表的題目用 `fig` 欄位給資料，由程式畫成圖（見〈圖表題〉），不可以在題幹寫「如圖」卻沒有 `fig`。
3. **一眼看完**：題幹盡量 ≤ 120 字（上限 180），選項 ≤ 60 字，手機直式畫面不必捲動。英文題幹以字母計，盡量 ≤ 132 個字元（111–115 學測詞彙題 50 題的題幹中位數 108、最長 132）。
4. **答案唯一且無爭議**：不可出現兩個都說得通的選項；不碰每年會變的數據（現行基本工資、最新選舉結果、最新統計數字等）。
5. **限 108 課綱學測範圍**：數學是 10 年級必修加 11 年級 A 類（數學 A）；數學 B 另有幾個 A 類沒有的主題，集中在「數B 專屬主題」單元。自然與社會只考部定必修（自然含「探究與實作」）；選修才教的公式或主題（例如變壓器、哈伯定律、光電方程式），即使在題幹附上公式也不要出。
6. **台灣用語、繁體中文**：機率（不是概率）、資訊（不是信息）、莫耳、氧化數、標準差、程式、品質…等，依台灣高中教科書用語。

### 例外：草稿區演算題

作答畫面有草稿區（平板常駐在旁邊，手機可以拉出來），所以數學、物理、化學，以及地科、生物的計算題，可以有**少量**需要動筆的題目：

- 只限 `level: 3`，約占該科題目的 15–20%；其餘題目照樣遵守第 1 點。
- 演算以 3–4 步為限，數字仍要設計成好算（整數、簡單分數、特殊角），不需要計算機。
- 題幹要給齊所需的數據與常數，不能依賴圖形。

### 演算題（`scratch: true`）

仿學測非選、選填與較長單選的計算題，給坐在桌前、打開草稿區認真算的時候練：

- 標 `scratch: true`，只能是 `level: 3` 的單選題，`formula` 一律 `false`（考的是多步推理，不是背單一公式）。
- 演算 4–6 步，要串起兩三個觀念（例如先由條件列式求出未知數，再代入另一個關係）；學測不能用計算機，數字仍要設計成手算算得完（約 3 分鐘內）。
- 四個選項都是數值，誘答是真的會算錯的結果：漏了一步、中途正負號或係數錯、單位沒換、用了錯的關係式。正解不要總是落在中間的值。
- 題幹上限仍是 180 字，給齊數據與常數；解析放寬到 220 字，要寫出完整的演算過程（關鍵式子與中間結果），讓算錯的人對得出自己錯在哪一步。
- 60 秒快閃不出演算題；作答畫面會提示可以打開草稿區。
- 四個選項都是同單位的單純數值（整數、小數、分數，可帶負號與共同單位，例如 `$\frac{5}{24}$`、`-2.5`、`12 g`）時，作答畫面先不給選項，讓玩家用數字鍵填答（像學測選填，`src/numeric.js`），填的值等於哪個選項就算選了哪個。所以選項要寫算得出的**精確值**，不要四捨五入的近似值（填 0.35 不會被當成 0.3）；含根號、π、科學記號或算式的選項照常以選項作答。
- 範圍限制和其他題目相同：選修才教的公式不會因為是演算題就可以出。

### 背公式的計算題

物理、化學、地科、生物各有一批 `formula: true` 的計算題，目的是逼學生把必修公式記熟：

- 題幹只給數據與常數，**不寫公式**，要自己想起公式才算得出來（例如給質量和速率求動能，不寫 $K=\frac12mv^2$）。
- 選項都是數值，誘答用套錯公式、漏了係數、單位沒換所算出的結果。
- 解析寫出用到的公式與算式。
- 公式要在必修（或必修明確延用的國中）範圍內。課綱的學習內容說明寫「不涉及計算」「定性」或只在選修出現的，不出計算題：
  - 物理：必修的牛頓定律「不涉及公式之推導與計算」、能量轉換「避免做定量推導及計算」。可以算的是 $a=\Delta v/\Delta t$、單一物體的 $F=ma$、$W=mg$、動能與位能的定義、功率、比熱與熱平衡、$v=f\lambda$、$E=hf$ 與能階、$E=mc^2$、萬有引力與庫侖力的平方反比、克卜勒第三定律、$I=V/R$、$P=IV$ 與電費、單位換算。不出：等加速度位移公式、摩擦係數、虎克定律、功的夾角、力學能守恆的定量計算、光電方程式、折射率、變壓器、輸電線損。
  - 化學：不出產率、氣體體積、限量試劑、氧化數、氧化還原反應的平衡、pOH、含結晶水的物質；同位素只用碳、氫。
  - 生物：不出等位基因頻率（族群遺傳是選修）、多基因遺傳的計算；有絲分裂不分前中後末期。
  - 地科：不出乾溼絕熱率、哈伯定律、地震波到時差求距離、地溫梯度。

### 多選題（`type: "ms"`）

學測數學、自然、國文都有大量多選題（111–115 學年度：數學約 27%、自然 32–45%、國文約 18%），要練「每個選項各自判斷」，不能用「四選一只有一個對」的刪去法：

- `choices` 剛好 5 個，`answer` 是正解選項索引的陣列（由小到大、不重複），至少 1 個正解。正解個數以 2、3 個為主，1 個與 4 個各約一成五，5 個全對偶爾出現就好，免得學生摸出「通常選兩三個」的規律。
- 每個選項都是一句可以單獨判斷對錯的敘述（或一個數值、一個詞語），不依賴其他選項；不可用「以上皆是」這類選項。錯誤選項只錯一個關鍵點，要是學生真的會犯的錯。
- 選項會被打亂：題幹和解析不可用 (A)(B) 或「第一個選項」指稱選項，改用選項裡的關鍵字。
- 措辭不能洩漏對錯：有「一定、所有、只要…就」的選項不能全是錯的，正確選項也要有直接、肯定的敘述。
- 手機上要放得下五個選項：題幹盡量 ≤ 100 字，選項盡量 ≤ 30 字（上限 60）。解析放寬到 220 字，逐一點出錯誤選項錯在哪裡。
- `level` 用 2 或 3。作答時選好再按「送出」，全對才算答對；畫面同時顯示學測的計分（答錯 k 個選項得 (5−2k)/5，低於 0 以 0 計），模擬考也照這個規則部分給分。

### 閱讀題組（`group` + `passage`）

學測國文約一半、英文約七成的分數在讀一篇文章後連答幾題（國文的現代文、陌生文言、詩詞與比較閱讀，英文的綜合測驗與閱讀測驗），單題刷不到這種讀長文、前後對照的能力：

- 一個題組是 2–5 題（共用選項的題組最多 7 題），共用同一篇文章。每題各自是完整的題目（`mc` 或 `ms`，不可是是非題），另外有：
  - `group`：題組代號 `<科目>-g001` 起的流水號（三或四位數），同題組的每一題都一樣。
  - `passage`：文章全文，同題組的每一題**逐字相同**（驗證器會比對）。段落用 `\n` 分開；國文的比較閱讀用「甲、」「乙、」開頭分段。
- 長度：國文 100–700 字（盡量 ≤ 550），英文 80–330 個字（約 2,000 字元以內，盡量 ≤ 280 字）。手機上文章在題目卡上方的框裡捲動，題幹仍要短（≤ 120 字），選項 ≤ 60 字。
- 每題的 `topic` 照它實際考的能力選：文言字詞義用「文言字詞」、修辭手法用「修辭」、詩詞的意象與情感用「詩詞曲」、英文空格考單字或片語就用該單元；考整篇的主旨、推論、段落關係、作者態度時，國文用「跨單元綜合」、英文用「轉折語與篇章」。題組裡的「跨單元綜合」題可以不寫 `links`（考的是閱讀理解，不一定結合特定單元）；有寫時仍要符合 links 的規則。
- **克漏字（綜合測驗）**：文章裡的空格寫成 `__1__`、`__2__`…（兩個底線包住編號，從 1 起依序），每題的題幹只放一個空格代號，固定寫成「__3__ 處最適合填入哪一個選項？」（篇章結構寫「哪一個句子」；空格題的題幹一律用這句中文，不套用英文科題幹用英文的規定）；選項是可以填進空格的字詞或片語，四個選項詞性相同。一篇 4–5 個空格，每格各出一題。
- **共用選項（英文文意選填、篇章結構）**：同組每一格的 `choices` 是同一組選項，**逐字相同、順序相同**（5–8 個，作答時不打亂，像試卷上的 (A)–(H)），`answer` 是這一格的正解在這組選項裡的索引；每個選項最多是一格的答案，而且選項至少比空格多 1 個（最後一格才不會用刪去法直接得分），答案不可照空格順序排成 A、B、C…。
  - 文意選填：一篇 180–240 字的短文、6 個空格、8 個字詞或片語選項（詞性混合，每個詞性至少兩個，學生要先看詞性與搭配縮小範圍）；每格各出一題，topic 用核心單字、進階單字或片語與搭配詞。
  - 篇章結構：一篇 220–320 字、分 4–5 段的文章，挖掉 4 個整句（多半是段落的主題句、轉折句或結論句），5 個句子選項（多 1 句干擾句，跟主題相關但放哪裡都不通順）；選項上限 120 字元，topic 用轉折語與篇章。
- **閱讀測驗**：題目問主旨、細節、推論、詞義、指涉、作者態度或段落功能，答案要能從文章找到依據，不能靠背景知識就答得出來；同一題組的題目不可互相洩漏答案。
- **數學與自然的題組**（仿學測自然的題組、數學 A 的混合題）：passage 是一段 100–450 字的情境——實驗步驟與結果、科學短文、觀測資料、生活中的數學模型——數據用文字或簡短條列寫出，不依賴圖片，可以用 LaTeX。每組 2–3 題（單選或多選，不加 `scratch`），由淺入深，至少一題要整合 passage 裡兩處以上的資訊；後一題要用到前一題的結果時，題幹自己給出需要的中間結果，免得前一題錯了後面全錯。每題的 `topic` 是它考的單元，題幹只寫這題要問的（不重貼情境）。
- 文章來源：
  - 現代文與英文文章自己寫，題材避開歷屆學測用過的主題；不要寫「原創」「自撰」這類字，也不要假託真實作者或媒體。
  - 文言文與詩詞只引用**確定存在、逐字正確**的原文（不可自己仿寫古文冒充原典），文末用括號注明出處，例如「（節錄自歐陽脩〈賣油翁〉）」。核心古文以外的篇章用「跨單元綜合」或對應的知識單元，不要標成「核心古文」。
- 題組的題目在一般練習裡會排在一起、先出文章；60 秒快閃不出題組。模擬考的國文卷、英文卷、自然卷各抽 3 組，數學卷抽 1 組混合題組，整組排在（同一科的）單題之後。

### 圖表題（`fig`）

學測自然與地理有三到四成的小題要讀圖表（物理 46%、化學 59%、地理 44%），數學的數據分析、公民的經濟題也常給圖或表。這類題目在題目上加 `fig` 欄位：**給的是資料，不是圖片**，App 用程式畫成 SVG 圖或資料表（`src/figure.js`），深色模式、螢幕閱讀器與「複製給 AI」都用同一份資料。

- 只能用在單選（`mc`）與多選（`ms`）的單題；題組的題目與是非題不可有 `fig`。60 秒快閃不出圖表題。
- **一定要看圖才答得出來，而且要用到本單元的觀念**：答案取決於從圖表讀到的數值、趨勢或比較。把圖拿掉也答得出來的不算圖表題；只會讀數字、不需要學科知識的也不算。
- 題幹盡量 ≤ 80 字（上限 120），寫明「如圖」或「如表」，數據放在圖裡、不要在題幹重複。選項盡量短（單選 ≤ 30 字、多選 ≤ 24 字），手機上圖、題幹與選項才放得下。
- 要讀的數值必須**讀得準**：關鍵的點落在刻度線或兩條刻度線的正中間，或用 `marks` 標出來；不要考必須估到小數才分得出選項的讀值。
- 圖裡的資料必須和答案、解析一致：曲線的點用程式照關係式算出來，解析寫出從圖表讀到的關鍵數值。資料要合乎科學事實與常理（例如氣候圖要像那種氣候、溶解度的數量級要對）。
- 圖中文字（軸標題、圖例、類別、標記）不能用 LaTeX，單位寫成 `m/s`、`°C`、`g/100 g 水`；只有表格的儲存格與標題可以用 `$...$`。多組資料用 `name` 分辨（甲、乙…），題幹與解析用這些名字指稱，不要說「藍色的線」（色盲或螢幕閱讀器使用者分不出來）。

五種圖（未列的欄位都不可有）：

| `type` | 用途 | 欄位 |
| --- | --- | --- |
| `line` | 折線與曲線：v-t 圖、溶解度曲線、加熱曲線、供需線、函數圖形 | `x`、`y`：`{ "label": "時間 (s)", "min"?, "max"?, "step"? }`；`series`：1–4 組 `{ "name"?, "points": [[x, y], …], "smooth"?, "dashed"? }`，每組 2–40 個點、x 由小到大；`marks`?：1–4 個 `{ "x", "y", "label" }` 標記點 |
| `scatter` | 散布圖：實驗數據點、相關與迴歸 | 同 `line`，每組 3–40 個點、不連線，不用 `smooth`、`dashed` |
| `bar` | 長條圖：各組比較、人口或產業結構 | `x`：`{ "label"?, "cats": ["甲", "乙", …] }`（2–8 類，每類 ≤ 6 字）；`y`：`{ "label", "min"?, "max"?, "step"? }`；`series`：1–3 組 `{ "name"?, "values": […] }`（和 `cats` 一一對應、不小於 0；類別數 × 組數 ≤ 18） |
| `climate` | 氣候圖：月均溫折線＋月降水量長條 | `temp`：12 個月均溫（°C）；`rain`：12 個月降水量（mm） |
| `table` | 資料表：實驗數據、各地指標、願付價格 | `cols`：2–5 欄的標題；`rows`：2–7 列，每列和 `cols` 一樣多格（數字或 ≤ 14 字的文字），第一欄是列的名稱 |

- 每種圖都可以有 `title`（≤ 30 字）。不只一組資料時每組都要有 `name`（≤ 8 字）。
- 座標軸沒寫 `min`／`max`／`step` 時自動取整齊的刻度（約 5 格；資料不小於 0 且最小值不到最大值一半時從 0 開始）。要學生讀特定數值時自己指定，讓那些值落在刻度上。
- `smooth: true` 把點連成平滑曲線（函數圖形、溶解度曲線），點要夠密（至少 7 個，轉折處多給幾個）而且不畫出每個點；沒有 `smooth` 的折線在點不超過 12 個時會畫出資料點。
- 驗證器會檢查格式（`checkFigure`），並擋下沒有 `fig` 卻寫「如圖」「如表」「下圖」「下表」的題目。

```json
{
  "id": "physics-9001",
  "subject": "physics",
  "topic": "牛頓運動定律",
  "type": "mc",
  "q": "一輛玩具車沿直線運動，速度與時間的關係如圖。哪一段時間內車子所受的合力為零？",
  "fig": {
    "type": "line",
    "x": { "label": "時間 (s)" },
    "y": { "label": "速度 (m/s)" },
    "series": [{ "points": [[0, 0], [2, 8], [6, 8], [8, 0]] }]
  },
  "choices": ["0–2 秒", "2–6 秒", "6–8 秒", "0–8 秒全程"],
  "answer": 1,
  "explain": "2–6 秒速度維持 8 m/s 不變，加速度為零，由 $F=ma$ 知合力為零。",
  "formula": false,
  "level": 2
}
```

### 非選擇題（`type: "open"`）

學測英文的中譯英、國文與社會的混合題簡答、自然的簡答與說明，都要**自己寫出答案**，選擇題練不到。這類題目沒有選項：作答畫面先請玩家在草稿區或紙上寫，按「看參考答案」後對照參考答案，自己勾選寫到了哪幾個評分要點；每個要點都寫到才算答對，沒全寫到就進錯題複習。

- 什麼時候用：答案是一句話或兩三句話、寫得出明確評分要點的題目——英文的中譯英（單句翻譯），其他科的簡答（說明原因、寫出判斷依據、列出步驟）。一個詞就答完的用單選題，沒有固定要點的長篇申論不要出。
- 欄位：`q` 題幹、`answer` 參考答案（**字串**，≤ 200 字元，盡量 ≤ 160）、`points` 評分要點（2–4 個字串，每個 ≤ 40 字元，互不相同）、`explain` 解析（和演算題一樣放寬到 220 字），加上 `id`、`subject`、`topic`、`level`。**不可有** `choices`、`formula`、`scratch`、`group`、`passage`、`fig`、`lv`。
- 英文的中譯英：題幹是一句中文（不套用英文科題幹用英文的規定，長度照中文題幹，盡量 ≤ 120 字），參考答案是英文句子，要點與解析用繁體中文（可以夾英文的片語與句型）。其他科的參考答案與要點都用繁體中文。
- **評分要點怎麼寫**：每個要點是玩家拿自己寫的答案對照參考答案後，**自己就能判斷有沒有做到**的具體項目，一個要點只看一件事：
  - 好的要點：「主要子句用過去完成式」「片語 take … for granted」「指出慣性（牛頓第一定律）」「說明腳受摩擦力而減速」。
  - 不好的要點：「文法正確」「意思通順」「答案完整」（太籠統，自己判斷不出來）；把兩件事塞在同一個要點；要點之間互相重疊。
  - 要點合起來要涵蓋這題真正在考的地方（關鍵的句型、片語、時態；簡答的關鍵概念與推論步驟），拼字、標點這類每題都一樣的要求不必列。
  - 要點照參考答案裡出現的順序排（作答畫面不打亂），玩家由上往下對照。
- 參考答案只寫一種最標準的寫法；其他可以接受的寫法、常見的錯誤寫在解析裡。解析要讓沒寫到的人知道每個要點為什麼重要。
- 60 秒快閃、公式特訓與模擬考不出非選擇題；作答速度不計時；答對後不問「猜的／不太確定」（自評已經表達了）。

```json
{
  "id": "english-9001",
  "subject": "english",
  "topic": "假設語氣與特殊句構",
  "type": "open",
  "q": "我當初不該把她的幫助視為理所當然。",
  "answer": "I should not have taken her help for granted.",
  "points": ["should not have + 過去分詞", "片語 take … for granted", "受詞是 her help"],
  "explain": "對過去做過的事後悔，用 should not have + 過去分詞；「視為理所當然」是 take … for granted，受詞放在中間。",
  "level": 2
}
```

## 欄位

| 欄位 | 型別 | 說明 |
| --- | --- | --- |
| `id` | string | `<科目>-001` 起的流水號（三或四位數），同檔內不可重複 |
| `subject` | string | 與檔名相同：`chinese` `english` `math` `physics` `chemistry` `biology` `earth` `history` `geography` `civics` |
| `topic` | string | 單元名稱，必須**逐字**取自 `src/units.js` 該科的清單（例如「三角函數」「孟德爾遺傳」） |
| `type` | `"mc"` / `"tf"` / `"ms"` / `"open"` | `mc` 四選一；`tf` 是非題；`ms` 多選題（見上方〈多選題〉）；`open` 非選擇題，自己寫、對照參考答案自評（見上方〈非選擇題〉） |
| `q` | string | 題幹 |
| `choices` | string[4] / string[5] | `mc` 剛好 4 個、`ms` 剛好 5 個，互不相同；`tf`、`open` 沒有 |
| `answer` | number / boolean / number[] / string | `mc` 為正確選項索引 0–3；`tf` 為 `true`（敘述正確）或 `false`；`ms` 為正確選項索引的陣列（由小到大）；`open` 為參考答案的字串（≤ 200 字元） |
| `points` | string[2–4] | 只有 `open` 才有：評分要點，每個 ≤ 40 字元、互不相同，是對照參考答案後自己判斷得出有沒有寫到的具體項目 |
| `explain` | string | 1–2 句解析（≤ 100 字），點出關鍵概念或公式，答錯時給學生看 |
| `formula` | boolean | 這題在考公式本身（背公式、套公式、公式辨識）時為 `true`；`open` 不寫這個欄位 |
| `level` | 1 / 2 / 3 | 1 基礎觀念、2 標準學測難度、3 需要多想一步（但仍可心算） |
| `links` | string[] | 只有「跨單元綜合」的題目才有：這題結合的 2–3 個同科單元（逐字取自 `src/units.js`，不可是「跨單元綜合」本身） |
| `scratch` | `true` | 只有「演算題」才有（見上方〈演算題〉）；其他題目不要寫這個欄位 |
| `group` | string | 只有閱讀題組的題目才有：題組代號 `<科目>-g001`（見上方〈閱讀題組〉） |
| `passage` | string | 只有閱讀題組的題目才有：題組共用的文章，同題組逐字相同 |
| `fig` | object | 只有圖表題才有：畫成圖或表的資料（見上方〈圖表題〉） |
| `lv` | 1–6 | 只有英文「核心單字」「進階單字」的單選題才有：考的字（正解；「'X' means」這類題是題幹裡的 X）在大考中心《高中英文參考詞彙表》的級數，答錯時解析旁會標「詞彙表第 N 級」。正解是片語、句子或不在詞表的題目不寫 |
| `kp` | string | 考點代號「單元序號-考點序號」（例如 `06-21`，見下方〈考點〉）。有考點清單的科目每題都要有；還沒有清單的科目不可寫 |

不可有其他欄位。

## 考點（`kp`）

單元底下再分一層考點（一個單元 10–24 個），出新題時用：單元裡還沒練過的考點先出、同一個考點不連著出（`src/priority.js` 的 `orderFresh`）。同樣做 110 題物理新題，碰到的考點從約 80 個變成約 106 個。

- 清單在 `src/data/concepts/<科目>.json`：`[{ unit, concepts: [{ id, name, scope }] }]`。`id` 是「單元序號-考點序號」（單元序號照 `src/units.js` 的順序，從 01 起），`name` 2–14 字、是給學生看的名稱，`scope` 一句話說明考什麼。「跨單元綜合」通常沒有自己的考點，題目標它結合的單元裡答題最關鍵的那個考點（國文例外：跨單元綜合大多是閱讀題組，考的是閱讀理解，有自己的考點）；其他單元的題目只能標自己單元的考點。
- `name` 會直接顯示給學生：作答後標在解析標題旁（「考點：○○」，作答前不顯示）、列在單元重點卡下方的考點清單、學習分析各科寫出練過幾個。名稱要讓學生一看就知道是哪個觀念。清單由 `src/data/concepts.js` 依科目另外下載（不在主程式裡）。
- 粒度：同一個考點的兩題，會其中一題的學生大概也會另一題（同一個觀念、同一種判斷或同一條關係式）。不照題型或難度分；不用「其他」「綜合」這種收容用的名字。每個考點至少要有題目。
- 十科都有（共 1,982 個考點：國文 147、英文 158、數學 337、物理 232、化學 255、生物 208、地科 208、歷史 181、地理 124、公民 132）。新增題目時要一併標 `kp`（還沒併入題庫的新題檔用 `--partial` 驗證時不要求）。
- 英文的單字單元每個字彼此獨立，考點改用「詞性＋語意範疇」分（例如「變化與影響動詞」），用來讓同一類的字不連著出；閱讀題組的小題依題幹、正解與解析判斷考的能力（主旨、指涉、推論…）。
- 標法（Codex 三輪）：第一輪每個單元讀完全部題目、訂清單並歸類；第二輪另一個任務只看清單、獨立歸類；兩輪不一致的題目交第三個任務照清單寫的界線裁決。其他九科在第一輪之後多一步：另一個任務審核清單的用語、範圍與界線（只改名稱與說明的文字）。兩輪一致的比例：物理 91.9%、國文 90.6%、英文 85.0%、數學 91.6%、化學 91.3%、生物 90.3%、地科 93.6%、歷史 94.9%、地理 93.2%、公民 95.0%；裁決時約四分之三採第二輪（第二輪看得到解析）。

## 單元與題量

- 單元清單在 `src/units.js`，玩家可以只練某幾個單元，所以**每個單元至少 100 題**（`MIN_PER_UNIT`），驗證器會擋下不足的單元。
- 同一單元內的題目要分散在不同考點；同一個知識點換句話說、只改數字的題目算重複，不要灌水。
- 題量大時先列出單元的考點清單，再依清單出題：同一考點最多 3 題，而且切入方式要不同（正向計算、反推條件、比較兩者、概念辨析、生活或實驗情境、常見迷思）。
- 釐清觀念的題目先列「觀念點清單」：每個觀念附 1–3 個學生常見的迷思，以及最容易混淆的對比觀念。同一觀念點最多 7 題，每題針對不同迷思或換一種問法（迷思檢驗、對比辨析、條件與反例、預測並說明理由、情境應用或數據判讀）；錯誤選項要是真實的迷思，解析點出正確觀念並說明陷阱錯在哪裡。
- 已經有玩家作答紀錄的題目（既有 id）不可改 id，也不要改題意，進度是用 id 記的。

### 特殊單元

- **跨單元綜合**（每科都有）：一題要同時用到同科兩三個單元的知識才答得出來，不是只在題幹提到另一個單元的名詞。`links` 列出結合的單元，第一個是主要的。學測的題組常常這樣跨章節命題。玩家關掉某個單元時，結合了它的跨單元題也不出（只留「跨單元綜合」時例外）。
- **探究與實作**（物理、化學、生物、地科）：自然科學探究與實作是部定必修，學測自然會考。用該科的實驗或觀測情境，考提出可檢驗的問題與假說、操縱／應變／控制變因、對照組、用文字描述的數據找趨勢、相關與因果、結論有沒有證據支持、實驗缺失與改進、模型的侷限。數據用文字或 3–4 組數字寫在題幹，不能依賴圖表。
- **數B 專屬主題**（數學）：只有學測數學 B 考、數學 A 不考的 11 年級 B 類內容：球面上的大圓小圓與經緯線、長方體展開圖的最短路徑、圓錐曲線的視覺認識（不考方程式）、設計與透視中的比例、由經緯度算空間坐標、連續複利與 $e$、自然對數、平均成長率、列聯表。
- **史料與歷史解釋**（歷史）：課綱「如何認識過去」——史料的種類與性質、作者立場與可信度、同一事件不同說法的比較、歷史事實與歷史解釋、從短史料判斷時代與事件。引用史料時只用確定存在的名句或文獻的大意，寫成「（大意）」；不可捏造掛在真實人物或文獻名下的引文。

## 撰寫規則

- **選項會被隨機打亂**：不可使用「以上皆是」「以上皆非」「(A)(B) 皆對」這類依賴順序的選項，也不要在選項前加 (A)(B) 編號。
- **誘答選項要合理**：用學生真的會犯的錯（正負號、公式記反、單位換算錯、相近概念混淆），不要放明顯荒謬的選項。
- **是非題**：敘述要明確，錯誤敘述只錯一個關鍵點，解析要指出錯在哪。是非題約占 25–30%。
- **公式用 LaTeX**：行內公式以 `$...$` 包住，例如 `$\sin^2\theta+\cos^2\theta=1$`。
  - JSON 字串裡的反斜線要寫兩次：`"$\\frac{1}{2}$"`。寫成 `"\frac"` 會被 JSON 解析成控制字元（驗證器會抓出來）。建議用程式（`JSON.stringify` / `json.dump(ensure_ascii=False)`）輸出檔案，不要手刻跳脫。
  - 公式裡不要放中文，必要時用 `\text{}`，或把中文移到 `$` 外。
  - 金額不要用 `$` 符號，寫「元」「美元」；真的需要字面錢字號時寫 `\$`。英文題沒有公式，驗證器會擋下英文題裡沒跳脫的 `$`（例如 $8,000 要寫成 `\$8,000`，JSON 裡是 `"\\$8,000"`）。
  - 只用 KaTeX 支援的指令；不要用 `\displaystyle` 以外的排版指令，也不要用 `$$...$$`。
- **化學式**用 LaTeX 下標：`$\mathrm{H_2SO_4}$`、`$\mathrm{Fe^{3+}}$`。
  - 反應式裡每個化學式各自包 `\mathrm{}`，`+` 與箭頭放在外面：`$\mathrm{2H_2}+\mathrm{O_2}\rightarrow\mathrm{2H_2O}$`。整條包在同一個 `\mathrm{}` 裡會變成一整塊，手機上無法換行而超出畫面（驗證器會擋）。
- **誘答不能靠措辭猜**：不要讓錯誤選項都寫成「只要…就」「必定」「完全」這類誇張的絕對說法、只有正解措辭溫和；四個選項語氣、長度要相近。
- **是非題也不能靠語氣猜**：錯的敘述不要都寫成「只要 X 就能 Y」「X 足以證明 Y」這類誇大語氣，對的敘述也不要都寫成「X 不表示 Y」「即使 X 仍可能 Y」這類修正語氣。每一科裡，兩種語氣的敘述各自都要對錯約各半：也要有「正確的絕對敘述」（例如「所有細胞都具有細胞膜」）和「錯誤的保留敘述」（例如「部分原核細胞具有由核膜包圍的細胞核」），或乾脆直接陳述內容、不用套語。
- **英文科**題幹與選項用英文，解析用繁體中文（附關鍵字中文意思）。例外：題組空格題固定的那句中文題幹，以及非選擇題的中譯英（題幹是中文句子、參考答案是英文）。
- **英文字彙程度**照大考中心《高中英文參考詞彙表（111 學年度起適用）》：111–115 學測詞彙題的 50 個正解是第 1 級 1、第 2 級 5、第 3 級 13、第 4 級 21、第 5 級 10 個，150 個誘答也沒有第 6 級。所以單字題的正解與誘答都用詞表內第 2–5 級的字（核心單字的正解第 2–4 級、進階單字第 4–5 級），不用第 6 級與表外字；文意選填偶爾可用第 1 級字的少見字義（如動詞 house、bridge）。
- **解析**要能讓答錯的人「看一眼就懂」，不要只寫「故選 B」。
