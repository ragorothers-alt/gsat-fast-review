# 題庫規範

題庫放在 `src/data/questions/<科目>.json`，每個檔案是一個 JSON 陣列。
寫完一定要跑驗證器，0 個錯誤才算完成：

```bash
node scripts/validate-questions.mjs src/data/questions/math.json
```

## 核心原則：不用紙筆也能作答

這個遊戲給學生在通勤、排隊時用手機刷題，**手邊沒有紙筆**。每一題都必須：

1. **20 秒內能心算或判斷**：數學、理化計算最多兩步，數字要小、能整除或好估算；需要列式、畫圖、長除法的題目不要出。
2. **純文字即可作答**：不能依賴圖片、圖表、地圖、示意圖。
3. **一眼看完**：題幹盡量 ≤ 120 字（上限 180），選項 ≤ 60 字，手機直式畫面不必捲動。
4. **答案唯一且無爭議**：不可出現兩個都說得通的選項；不碰每年會變的數據（現行基本工資、最新選舉結果、最新統計數字等）。
5. **限 108 課綱學測範圍**：數學以數學 A 為主（涵蓋數學 B），自然與社會只考部定必修。
6. **台灣用語、繁體中文**：機率（不是概率）、資訊（不是信息）、莫耳、氧化數、標準差、程式、品質…等，依台灣高中教科書用語。

### 例外：草稿區演算題

作答畫面有草稿區（平板常駐在旁邊，手機可以拉出來），所以數學、物理、化學可以有**少量**需要動筆的題目：

- 只限 `level: 3`，約占該科題目的 15–20%；其餘題目照樣遵守第 1 點。
- 演算以 3–4 步為限，數字仍要設計成好算（整數、簡單分數、特殊角），不需要計算機。
- 題幹要給齊所需的數據與常數，不能依賴圖形。

## 欄位

| 欄位 | 型別 | 說明 |
| --- | --- | --- |
| `id` | string | `<科目>-001` 起的流水號（三或四位數），同檔內不可重複 |
| `subject` | string | 與檔名相同：`chinese` `english` `math` `physics` `chemistry` `biology` `earth` `history` `geography` `civics` |
| `topic` | string | 單元名稱，必須**逐字**取自 `src/units.js` 該科的清單（例如「三角函數」「孟德爾遺傳」） |
| `type` | `"mc"` / `"tf"` | `mc` 四選一；`tf` 是非題 |
| `q` | string | 題幹 |
| `choices` | string[4] | 只有 `mc` 才有，剛好 4 個、互不相同 |
| `answer` | number / boolean | `mc` 為正確選項索引 0–3；`tf` 為 `true`（敘述正確）或 `false` |
| `explain` | string | 1–2 句解析（≤ 100 字），點出關鍵概念或公式，答錯時給學生看 |
| `formula` | boolean | 這題在考公式本身（背公式、套公式、公式辨識）時為 `true` |
| `level` | 1 / 2 / 3 | 1 基礎觀念、2 標準學測難度、3 需要多想一步（但仍可心算） |

不可有其他欄位。

## 單元與題量

- 單元清單在 `src/units.js`，玩家可以只練某幾個單元，所以**每個單元至少 100 題**（`MIN_PER_UNIT`），驗證器會擋下不足的單元。
- 同一單元內的題目要分散在不同考點；同一個知識點換句話說、只改數字的題目算重複，不要灌水。
- 題量大時先列出單元的考點清單，再依清單出題：同一考點最多 3 題，而且切入方式要不同（正向計算、反推條件、比較兩者、概念辨析、生活或實驗情境、常見迷思）。
- 已經有玩家作答紀錄的題目（既有 id）不可改 id，也不要改題意，進度是用 id 記的。

## 撰寫規則

- **選項會被隨機打亂**：不可使用「以上皆是」「以上皆非」「(A)(B) 皆對」這類依賴順序的選項，也不要在選項前加 (A)(B) 編號。
- **誘答選項要合理**：用學生真的會犯的錯（正負號、公式記反、單位換算錯、相近概念混淆），不要放明顯荒謬的選項。
- **是非題**：敘述要明確，錯誤敘述只錯一個關鍵點，解析要指出錯在哪。是非題約占 25–30%。
- **公式用 LaTeX**：行內公式以 `$...$` 包住，例如 `$\sin^2\theta+\cos^2\theta=1$`。
  - JSON 字串裡的反斜線要寫兩次：`"$\\frac{1}{2}$"`。寫成 `"\frac"` 會被 JSON 解析成控制字元（驗證器會抓出來）。建議用程式（`JSON.stringify` / `json.dump(ensure_ascii=False)`）輸出檔案，不要手刻跳脫。
  - 公式裡不要放中文，必要時用 `\text{}`，或把中文移到 `$` 外。
  - 金額不要用 `$` 符號，寫「元」「美元」；真的需要字面錢字號時寫 `\$`。
  - 只用 KaTeX 支援的指令；不要用 `\displaystyle` 以外的排版指令，也不要用 `$$...$$`。
- **化學式**用 LaTeX 下標：`$\mathrm{H_2SO_4}$`、`$\mathrm{Fe^{3+}}$`。
- **英文科**題幹與選項用英文，解析用繁體中文（附關鍵字中文意思）。
- **解析**要能讓答錯的人「看一眼就懂」，不要只寫「故選 B」。

## 範例

```json
[
  {
    "id": "math-001",
    "subject": "math",
    "topic": "三角函數",
    "type": "mc",
    "q": "在 $\\triangle ABC$ 中，$a=7$、$b=5$、$c=3$，則 $\\angle A$ 為多少？",
    "choices": ["$120^\\circ$", "$60^\\circ$", "$150^\\circ$", "$90^\\circ$"],
    "answer": 0,
    "explain": "餘弦定理 $\\cos A=\\frac{b^2+c^2-a^2}{2bc}=\\frac{25+9-49}{30}=-\\frac{1}{2}$，故 $A=120^\\circ$。",
    "formula": true,
    "level": 2
  },
  {
    "id": "biology-001",
    "subject": "biology",
    "topic": "孟德爾遺傳",
    "type": "tf",
    "q": "基因型 $Aa$ 的個體自交，子代表現型（顯性：隱性）比例為 $1:2:1$。",
    "answer": false,
    "explain": "$1:2:1$ 是基因型比例（AA:Aa:aa）；完全顯性時表現型比例為 $3:1$。",
    "formula": false,
    "level": 1
  }
]
```
